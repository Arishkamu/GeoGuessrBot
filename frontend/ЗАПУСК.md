# Запуск фронтенда

Всё делать в этой папке.

    npm install                          # один раз
    npm run build                        # после каждого обновления файлов
    npm run preview -- --port 8000       # открыть http://localhost:8000

Туннель (в другом окне): cloudflared tunnel --url http://localhost:8000
Бэкенд (в третьем окне, из корня репозитория): uvicorn backend.app.ui_main:app --port 8080

Проверка без бэкенда: http://localhost:8000/?mock
Список стран правится в src/countries.js.
